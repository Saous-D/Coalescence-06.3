# Projet Flask de Segmentation

## Installation
Ouvrez un terminal dans le dossier du projet.

### Sous Linux/Mac
chmod +x install.sh
sh install.sh

#### Sous windows
./install.bat

l'installation peut prendre du temps, il faut bien attendre la fin de l'installation des packages.

une fois cela fait, allez sur le lien suivant:  http://127.0.0.1:5000

une image satellite en exemple est présente dans le dossier : ./uploads
